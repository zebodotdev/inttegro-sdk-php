MessageTemplate.php : 17

A reusable SMS or email template, including its variables, content, safety results, and lifecycle state.

This immutable value hydrates decoded API snake_case data into typed camelCase properties. Use fromArray() for wire data; toArray(), array access, and JSON serialization expose the API wire representation. Nullable properties correspond to optional API fields.
