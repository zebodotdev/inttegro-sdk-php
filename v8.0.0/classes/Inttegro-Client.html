Client.php : 39

Authenticated entry point for every Inttegro API resource.

Construct one client with a server-side secret key, then use its typed resource properties for operations. The client owns a shared HTTP transport so timeout, telemetry, error reporting, and test-adapter configuration apply consistently to every request.

Client.php : 107

Creates a client and binds every resource to one authenticated transport.

public __construct(string $apiKey[, string $baseUrl = 'https://api.inttegro.com' ][, int $timeout = 30 ][, mixed $adapter = null ][, bool $telemetryEnabled = true ][, TracerProviderInterface|null $tracerProvider = null ][, TextMapPropagatorInterface|null $propagator = null ][, callable(ErrorReport): void|null $errorReporter = null ][, string $errorReportingPolicy = 'unexpected' ]) : mixed

Keep apiKey in a server-side secret store. The SDK never configures or exports telemetry by itself; optional OpenTelemetry and error-reporting collaborators remain application-owned.

Parameters
$apiKey : string

Required Inttegro secret key. Never expose it to browser or mobile code.

$baseUrl : string = 'https://api.inttegro.com'

API origin; normally leave this at the production default.

$timeout : int = 30

Request timeout in seconds.

$adapter : mixed = null

Optional transport adapter used primarily for deterministic tests.

$telemetryEnabled : bool = true

Whether to create vendor-neutral OpenTelemetry spans.

$tracerProvider : TracerProviderInterface|null = null

Application-owned tracer provider.

$propagator : TextMapPropagatorInterface|null = null

Application-owned trace propagator.

$errorReporter : callable(ErrorReport): void|null = null

Privacy-safe terminal-failure callback.

$errorReportingPolicy : string = 'unexpected'

Either unexpected or all.

Tags
throws
InvalidArgumentException

When the API key is empty.
